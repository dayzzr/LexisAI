Arquitetura e Privacidade

Motor de Execução Local: O Lexis AI roda Python nativamente no navegador usando Pyodide (Dados) e Skulpt (Gráficos).

Privacidade de Dados: O processamento de planilhas CSV é 100% contido no seu dispositivo. Nenhum dado corporativo é enviado à nuvem.

Agente Groq LLM: Apenas o texto digitado na aba "Agente IA (Código)" e o conteúdo do editor são processados via API para correção de scripts.
