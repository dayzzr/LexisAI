Manual do Usuário & Segurança Lexis AI

1. Visão Geral do Lexis AI

O Lexis AI — Enterprise Data Studio é um ambiente de desenvolvimento (IDE) e análise avançada de dados multiplataforma. Sem necessidade de servidores locais ou instalações de pacotes, ele transforma seu navegador em uma robusta estação de engenharia de dados e prototipagem de código.

2. Motores de Execução (Engines)

O ambiente suporta dois motores distintos para diferentes casos de uso, selecionáveis na barra superior:

  • Motor Gráfico (Skulpt): Processador leve voltado para lógica de programação estruturada e interfaces visuais nativas (como a biblioteca turtle). Ideal para scripts algorítmicos.
  • Motor de Dados (Pyodide): Ambiente Python completo que compila diretamente em WebAssembly. Vem com pandas, numpy, e matplotlib pré-instalados. Obrigatório para a leitura e manipulação de arquivos grandes e planilhas (CSV).

3. Fluxo de Trabalho com Arquivos (CSV)

  1. Mude o seletor no topo para Motor de Dados e aguarde o status indicar verde ("Motor de Dados Pronto").
  2. Clique em Anexar Arquivo e selecione seu .csv. Ele será carregado de forma invisível no sistema de arquivos virtual da memória RAM.
  3. Trabalhe com o arquivo via código usando pd.read_csv('/seu_arquivo.csv') ou chame o Lexis Copilot para extrair insights automáticos.

4. Lexis Copilot (Assistente Híbrido)

O botão Copilot abre o terminal de Inteligência Artificial que atua em duas frentes independentes:

  • Processar Dados (Offline): Executa operações de sumarização e limpeza do CSV diretamente no seu navegador, sem enviar nenhuma linha da sua planilha para a internet.
  • Agente IA (Código): Faz a leitura do script atual no seu editor de código e conecta-se via API segura ao modelo Groq LLaMA para resolver bugs, sugerir lógicas e explicar erros.

5. Teclado Virtual para Dispositivos Móveis

Para facilitar o uso em iPads e iPhones, o Lexis AI dispõe de uma barra de ferramentas móvel localizada logo abaixo das abas do editor. Ela injeta instantaneamente parênteses, chaves, aspas e gerencia o cursor automaticamente para aumentar a produtividade ao programar sem um teclado físico.

Disclaimer de Segurança & Zero-Trust

O desenvolvimento do Lexis AI obedece rigidamente aos princípios de Privacy by Design e Zero-Trust Frontend.

  • Isolamento Absoluto de Dados: O processamento do Motor de Dados ocorre de forma estritamente local (no lado do cliente) via tecnologia WebAssembly. Nenhum arquivo CSV, planilha ou dado interno é enviado ou compartilhado com servidores externos ou plataformas de IA de terceiros. Os dados residem exclusivamente na memória volátil do seu dispositivo e deixam de existir quando a aba é fechada.
  • Blindagem de Credenciais Backend: O acesso do Agente IA à rede neural é feito por meio de um intermediário anônimo (Cloudflare Workers). Nenhuma chave de API ou token de acesso fica exposto no código-fonte ou no console do navegador, tornando o app imune a engenharia reversa.
  • Prevenção contra XSS e Injeções: As interações dinâmicas, terminais e saídas HTML são sanitizadas em tempo real através da biblioteca de nível militar DOMPurify, bloqueando qualquer injeção de payload malicioso no DOM.
